# Lab 2: Rock-Paper-Scissors

A mini Rock-Paper-Scissors game built with Java and XML layout in Android Studio.

## Files
- `PaperScissorsRock.java` — Game logic for player choices, opponent move generation, and outcome evaluation.
- `activity_rock_paper_scissors.xml` — XML layout for the game screen.
- `screenshot_start.png` — Screenshot of the initial/start state.
- `screenshot_end.png` — Screenshot of the game outcome/end state.
