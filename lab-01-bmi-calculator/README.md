# Lab 1: BMI Calculator

A simple Android app built with Java and XML layout to calculate Body Mass Index (BMI) and display results.

## Files
- `CalculateBMI.java` — Activity logic handling user input and BMI calculation.
- `activity_calculate_bmi.xml` — XML layout for the calculator interface.
- `screenshot_main.png` — Screenshot of the main input screen.
- `screenshot_result.png` — Screenshot of the calculated result screen.
