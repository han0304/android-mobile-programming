# Android Mobile Programming Coursework

An Android Studio (Java) repository featuring an independent capstone project—**Playing Card Recognizer**—alongside three standalone coursework exercises covering UI layouts, input handling, and game logic.

## Featured Project
- `playing-card-recognizer/` — Standalone Android app built with Java, CameraX, Google ML Kit Text Recognition, and `TextToSpeech` to recognize playing cards and announce results aloud, accompanied by a project report and screenshot.

## Coursework Labs
- `lab-01-bmi-calculator/` — BMI calculator app with input layout and result display screens.
- `lab-02-rock-paper-scissors/` — Rock-Paper-Scissors mini game with start and end states.
- `lab-03-profile-info/` — Simple profile/information screen built with Java and XML layout.

## Tech Stack
- **Language & IDE:** Java, Android Studio
- **APIs & UI:** Android SDK, XML Layouts, CameraX, ML Kit Text Recognition, `TextToSpeech`
